# ✈️ SkyFare Predictor

## Overview
This repository contains a Machine Learning project designed to predict airline flight prices based on historical data. By analyzing various features such as airline, source, destination, departure time, and total stops, the model provides accurate fare estimates.

## 🚀 Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Visualization:** Matplotlib, Seaborn
* **Deployment/UI:** Streamlit

## ⚙️ Installation & Setup
1. Clone this repository
2. Create a virtual environment: `python3 -m venv venv`
3. Activate the environment: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
